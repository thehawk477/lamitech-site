# Lami Tech Repair website

One-page site for Lami Tech Repair, game controller and console repair in Peabody and the North Shore, MA.

Live: https://lamitechrepair.pages.dev

## How it's hosted
Cloudflare Pages, connected to this repo. Every push to `main` deploys automatically.

Cloudflare Pages settings:
- Production branch: `main`
- Framework preset: None
- Build command: (empty)
- Build output directory: `/`

## Files
- `index.html` - the whole site (styles and script inline)
- `favicon.ico`, `favicon.png`, `apple-touch-icon.png` - browser and phone icons
- `og-image.png` - preview image when the link is shared on Facebook or in texts
- `robots.txt`, `sitemap.xml` - help search engines find the site
