Accessibility

Last updated: November 18, 2026

I want everyone to be able to use this website and reach Lami Tech Repair, including people who use screen readers, keyboards, magnification or other assistive technology.

What I've done

  • The site is built to follow the Web Content Accessibility Guidelines (WCAG) 2.2, Level AA.
  • Text has strong color contrast against the background, and the page works when zoomed in.
  • Everything can be reached with a keyboard, with a visible focus outline and a "Skip to main content" link.
  • Images and icons have text descriptions or are hidden from screen readers when they're only decoration.
  • The moving background at the top can be paused with the "Pause animation" button, and it stays still if your device is set to reduce motion.
  • The site is checked with automated accessibility testing tools.
